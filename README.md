# Week 12 Homework Report: ARIA v8.0 — The Classification Engine

## Abstract (摘要)

將 ARIA 系統升級至 v8.0 核心分類引擎，針對 2024 年 0403 花蓮地震後的太魯閣與秀林地區進行多光譜衛星影像土地覆蓋分類。研究利用 STAC API 獲取 Sentinel-2 核心波段資料（B02, B03, B04, B08, B11, B12），首先透過 K-means 非監督式分類進行特徵空間探索，隨後利用 Google Earth Pro 建立純淨向量樣本，訓練隨機森林 (Random Forest) 分類模型。內部驗證顯示模型具備高精確度（隨機森林測試集整體準確度達 90% 以上）；然而，與農業部水土保持署 (SWCB) 官方發布之「新生崩塌地」進行外部獨立驗證時，空間交併比 (IoU) 僅為 0.82%。分析顯示，此顯著落差主因於兩者在「廣義地表裸露」與「新生災害崩塌」之間的語意定義落差（Semantic Mismatch），以及深山峽谷的地形陰影遮蔽所致。本分類圖資後續可作為災後交通路網中斷預判與避難所安全性評估之決策輔助。

## Task 1: K-means Unsupervised Classification (非監督式分類探索)

### 1. 影像預處理與特徵矩陣建置
設定研究區邊界 `TAROKO_BBOX = [121.40, 24.10, 121.80, 24.25]`。透過 STAC API 篩選震後無雲之 Sentinel-2 L2A 影像，並套用場景分類圖層 (SCL) 剔除雲、雲影及冰雪像素。將 6 個反射率波段除以 10000.0 還原為地表反射率，並將 3D 影像陣列重塑為 2D 特徵矩陣 $X$（形狀為 `(n_pixels, 6)`）。

### 2. K-means 群集光譜分析 (K=5)
在不提供任何先驗標籤的情況下，執行 K-means 演算法將有效像素劃分為 5 個群集。計算各群集之平均反射率光譜特徵曲線如下表：

| 群集編號 (Cluster ID) | 藍光 (B02) | 綠光 (B03) | 紅光 (B04) | 近紅外 (B08) | 短波紅外1 (B11) | 短波紅外2 (B12) | 建議賦予之物理地物類別 |
|-------------------|-----------|-----------|-----------|------------|----------------|----------------|---------------------|
| **Cluster 0** | 0.128     | 0.160     | 0.131     | 0.528      | 0.311          | 0.193          | **森林 (Forest)** |
| **Cluster 1** | 0.191     | 0.183     | 0.171     | 0.169      | 0.168          | 0.157          | **水體 / 陰影 (Water/Shadow)** |
| **Cluster 2** | 0.238     | 0.259     | 0.256     | 0.368      | 0.358          | 0.289          | **裸露地 / 崩塌地 (Bare/Landslide)** |
| **Cluster 3** | 0.125     | 0.148     | 0.130     | 0.412      | 0.278          | 0.181          | **農地 (Cropland)** |
| **Cluster 4** | 0.425     | 0.435     | 0.431     | 0.527      | 0.515          | 0.438          | **建物 / 高亮河床 (Built-up/Reflective)** |

### 3. 光譜解譯討論
* **易解譯群集：** Cluster 0 具備極為典型的植被光譜特徵，在紅光 (B04) 出現葉綠素吸收谷，並在近紅外 (B08) 出現強烈的細胞結構反射突起（反射率達 0.528），判定為茂密森林。Cluster 1 則在紅外線波段（B08, B11, B12）平貼谷底，吻合水分子強烈吸收紅外光的物理特性，判定為太平洋水體。
* **難解譯群集：** Cluster 4 全波段反射率皆高於 0.42。在山區地貌中，此特徵除了代表都市建物鋪面外，亦高度混雜了太魯閣特有的白色大理石礫石河床，甚至包含未被 SCL 完全濾除的薄雲殘留，存在明顯的光譜混淆（Spectral Confusion）。

## Task 2: Random Forest Supervised Classification (監督式分類與預測)

### 1. 訓練樣本收集策略
使用 Google Earth Pro 針對太魯閣及新城沖積扇進行目視判讀，依據「純度大於面積」之原則，排除混合像素邊界，於各類別均勻圈選 2-3 個純淨多邊形。利用 Python 的 `xml.etree.ElementTree` 解析 `training_samples.kml` 檔案，穿透資料夾階層萃取 Placemark 幾何資料。將樣本之地理座標系 (EPSG:4326) 強制 reproject 轉換至與衛星影像一致的投影座標系，隨後利用 `rasterio.features.rasterize` 轉換為網格標籤。

### 2. 隨機森林模型訓練
以 80/20 比例切分訓練集與測試集，並配置 `stratify=y` 確保類別比例均衡。訓練包含 200 棵決策樹的隨機森林分類器（開啟 `oob_score=True`）。
* **訓練集準確度 (Training Accuracy)：** 1.000 (100%)
* **測試集準確度 (Test Accuracy)：** 0.942 (94.2%)

### 3. 特徵重要性 (Feature Importance) 分析
隨機森林模型輸出的各波段權重分配如下：
* **SWIR1 (B11):** 0.228 *(最高)*
* **NIR (B08):** 0.187
* **Red (B04):** 0.168
* **SWIR2 (B12):** 0.168
* **Blue (B02):** 0.158
* **Green (B03):** 0.092 *(最低)*

**物理意義解釋：** 短波紅外光 (B11) 對地表含水量與土石礦物成分具有極高的鑑別力。山體崩塌後，地表從高含水的綠色樹冠轉變為乾燥、高反射的裸露岩土，B11 能最敏銳地捕捉此項突變。近紅外光 (B08) 則為植被細胞結構的黃金指標，能有效將廣大山區的森林與其餘地物分離。兩者權重相加超過 40%，證實紅外線波段為災後土地覆蓋分類的核心支柱。

## Task 3: Accuracy Assessment & Independent Validation (精度評估與外部驗證)

### Part A: 內部精度指標
經由測試集預測產製之混淆矩陣 (Confusion Matrix) 顯示，模型對 Forest、Water、Cropland 的分類效能極佳。主要之 off-diagonal 誤判集中於 **Bare (裸露地)** 與 **Built-up (建物)** 之間（共有 7 個像素發生交互誤判），此現象導因於混凝土鋪面與岩石沙土在光學光譜上的本質雷同。模型之袋外準確度 (OOB Accuracy) 為 93.85%，與測試集準確度 (94.2%) 高度互證，無過度擬合 (Overfitting) 現象。

### Part B: 農業部水土保持署 (SWCB) 獨立驗證與疊圖分析
導入官方 `20240802新生崩塌地.kml` 向量圖資，裁切至研究區邊界並光柵化後，與模型分類結果中之「裸露地/崩塌地 (Class 2)」進行空間像素級交叉比對，計算之空間重疊指標如下：
* **偵測率 (Recall / Detection Rate):** 0.523 (52.3%)
* **精確率 (Precision):** 0.012 (1.2%)
* **交併比 (IoU / Jaccard Index):** 0.0082 (0.82%)

### 空間誤差與不確定性討論
空間疊圖結果呈現大面積的 **黃色區塊 (False Positives, 誤報)** 與部分 **紅色區塊 (False Negatives, 漏報)**，其背後具備深刻的遙測實務物理原因：
1. **語意定義落差 (Semantic Mismatch) —— 誤報的主因：** 隨機森林模型係依據「光譜特徵」將地表無植被覆蓋的灰白區域判定為裸露地。因此，長期存在、不具災害威脅的**「立霧溪寬闊礫石河床」與「既有採礦場」**，皆被自動歸類為 Bare。然而，水保署的官方圖資僅標記「0403地震所引發的『新生』邊坡崩塌」，刻意排除一般河床。此定義上的本質差異導致模型產生高達 44,769 個像素的誤報，使 Precision 與 IoU 數據受到極度稀釋。
2. **地形陰影遮蔽 —— 漏報的主因：** 太魯閣山區地形極度陡峭狹谷縱橫。衛星通過時（上午10時許），陡峭陽光入射角在背風面與深谷產生深邃的地形陰影。藏匿於陰影內的邊坡崩塌地因缺乏光源，其反射率極低，導致模型將其誤判為 Water 或 Forest，造成大範圍漏報（紅色區塊集中於西方深山谷地）。
3. **解析度與時間差限制：** Sentinel-2 之 20 米解析度難以辨識小於 400 平方公尺的細碎滑坡（混合像素效應）；且衛星拍攝與官方人工航空照片判釋（8月）存在時間差，部分早期崩塌可能已生長先鋒植物（綠化），引發光譜時空變異。

## Reflection: From Thresholds to Classifiers (技術升級反思)

從 Week 8-10 的「單一閾值判斷法」跨入 Week 12 的「多波段機器學習分類器」，是 ARIA 系統架構上的本質飛躍：

1. **多維特徵空間的解放：** 傳統閾值法（如 $	ext{NDVI} > 0.4$ 或 $	ext{SAR} < -18	ext{ dB}$）如同在單一維度上拉一條死板的切線，一次只能區分兩種地物。然而，真實世界是複雜的多維光譜疊加。隨機森林能同時調動 6 個光譜波段，在六維空間中勾勒出複雜的非線性超平面邊界，從而實現單次分類出五種主流地物。
2. **對抗「同譜異物」的韌性：** 在閾值法中，「枯死植被」與「乾燥裸土」的 NDVI 往往重疊而無法區分。ARIA v8.0 透過隨機森林引進了特徵重要性居首的 SWIR1 波段，結合可見光與近紅外，讓模型學會了複雜的物理組合規則。
3. **工程代價的移轉：** 閾值法的瓶頸在於「人類調整參數的痛苦」，需要花費大量時間目視猜測切點。分類器則將瓶頸移轉至「訓練樣本的品質控制」。如本週實務所示，多邊形只要圈選到一絲地形陰影或混合邊界，就會發生「Garbage in, Garbage out」的連鎖效應。理解演算法底層的物理局限與語意落差，是工程師操作機器學習時最核心的專業素養。
